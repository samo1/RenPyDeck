A game manager and launcer for RenPy games.
Configurable folder locations.
Folder 1: Download folder - this will contain downloaded games (compressed archives). For examples you can see files in `download` folder.
Folder 2: Game folder - this will contain extracted games. For examples you can see files in `game` folder.
This launcer is mainly intended to be run on the Steam Deck.
Windows only games will be ignored, only games that contain Linux shell script to run the game will be supported.
When unpacking the game, the files must always go to a subfolder of the game folder. Make sure to create the subfolder if the archive does not already contain one.
It will be a graphical program with user interface. It will contain the list of downloaded games and a list of installed games. Functionality will include installing, running, and uninstalling games.
Game installation means unpacking the game from the download folder into game folder.
Some archives does not contain the executable permission set correctly, this launcher will fix it for the shell script and the libraries under the lib folder.
The user interface must contain an Exit button, because Steam Deck does not display window decorations by default.
The project will be written in Python, similar to Ren'Py engine.
This application will be distributed as a single-file flatpak bundle.
